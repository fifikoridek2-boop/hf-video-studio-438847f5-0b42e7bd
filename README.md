# Hyperframes Cloud Render Studio

مستودع آلي مخصص لرندر فيديوهات الموشن غرافيك عبر **GitHub Actions** باستخدام محرك **Hyperframes**.

- `shared-assets/`: مكتبة العناصر المشتركة (الشخصية الأساسية، شخصيات Flork، الستيكرات، الخطوط، المؤثرات الصوتية).
- `videos/<video_id>/`: مجلدات بيئة كل فيديو مكتملة وجاهزة للرندر المستقل.
- `.github/workflows/render-video.yml`: ملف أتمتة الرندر وإصدار روابط التحميل المباشرة بصيغة MP4.
