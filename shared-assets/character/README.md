# مجلد الشخصية الرمزية (Your Custom Persona / Character)

هذا المجلد مخصص لوضع صور شخصيتك الكرتونية أو الرمزية الخاصة بك، لتحل محل شخصية رأس التلفاز في فيديوهات المونتاج القادمة.

---

## 🎨 1. الوضعيات الموصى بها (Recommended Poses)

لتحقيق حركة حية ومرنة ومتفاعلة مع سيناريو الشرح، يُفضل توفير الشخصية بخلفية شفافة (PNG أو WebP أو SVG شفاف) مع التسميات التالية:

1. **`idle.png`**: الوضعية العادية (الشخصية تنظر للكاميرا بابتسامة خفيفة أو مظهر واثق).
2. **`typing.png`**: الشخصية تطبع على لابتوب أو جالسة على مكتب.
3. **`explaining.png`**: الشخصية تشير بيدها أو تشرح وتتحدث بحماس.
4. **`thinking.png`**: الشخصية تفكر أو محتارة (علامات استفهام أو يد على الذقن).
5. **`shocked.png`**: الشخصية مصدومة أو متفاجئة (للأسئلة القوية أو المشاكل التقنية).
6. **`happy.png`**: الشخصية سعيدة أو تحتفل بنجاح الكود / الشرح.

---

## 🛠️ 2. أفضل أدوات مجانية وشبه مجانية لصناعة شخصيتك:

إذا لم تكن لديك رسومات جاهزة لشخصيتك، فإليك أفضل الأدوات لإنشائها:

1. **[Recraft.ai](https://www.recraft.ai/) (مجاني جزئياً)**:
   - أقوى أداة متخصصة لإنشاء رسومات وفيكتور (Vector / SVG) وشخصيات متطابقة الهوية (Consistent Characters) بخلفية شفافة فورية تناسب الموشن جرافيكس.
2. **[Blush.design](https://blush.design/) (مجاني بالكامل)**:
   - مكتبة رسومات توضيحية لشخصيات متكاملة بريشة فنانين عالميين، تتيح لك تركيب الوجه، الشعر، والملابس وتنزيلها PNG شفافة.
3. **[Ready Player Me](https://readyplayer.me/) (مجاني بالكامل)**:
   - صناعة شخصيات أفاتار ثلاثية الأبعاد انطلاقاً من صورتك الحقيقية مع إمكانية تصدير وضعيات مختلفة.
4. **[Leonardo.ai](https://leonardo.ai/) / Midjourney**:
   - عبر أمر (Character Sheet): طلب الشخصية بوضعيات مختلفة على خلفية بيضاء ثم تفريغها بضغطة زر.
